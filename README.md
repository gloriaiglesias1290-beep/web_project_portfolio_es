# Portfolio Web – Gloria Iglesias López

## Descripción

Este proyecto corresponde a un portafolio personal desarrollado como parte del bootcamp de Desarrollo Web de TripleTen.

El sitio presenta mi perfil como desarrolladora web Full-Stack Junior e incluye una sección de presentación personal, habilidades técnicas, proyectos destacados y datos de contacto. El objetivo fue crear una interfaz moderna, limpia y completamente responsiva siguiendo un diseño proporcionado en Figma.

## Funcionalidades

- Presentación personal (Hero).
- Sección de habilidades con tecnologías utilizadas.
- Tarjetas de proyectos con enlaces a la demostración y al repositorio de GitHub.
- Sección de contacto con enlaces a redes sociales.
- Diseño responsivo para escritorio, tablet y dispositivos móviles.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- BEM (Block Element Modifier)
- Tipografías locales mediante `@font-face`
- Git
- GitHub

## Características técnicas

- Maquetación basada en Flexbox y CSS Grid.
- Diseño responsivo utilizando puntos de ruptura para escritorio, tablet y móvil.
- Organización del código siguiendo la metodología BEM.
- Uso de `@font-face` para cargar fuentes locales.
- Imágenes optimizadas para mejorar el rendimiento.
- Efectos visuales mediante gradientes, pseudo-elementos (`::after`) y transiciones CSS.
